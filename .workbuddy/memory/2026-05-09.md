### 核心结论

**产品定位**：图片瀑布流为主入口（类Pinterest/小红书逛感），不是"查字典"式的场景漏斗。用户被好看的成片吸引后点进去看参数，支持筛选但筛选是辅助非主入口。

**用户画像**（4类）：
1. 直出党——不想后期，要相机直出好看
2. 场景复刻党——看到好图想复刻，先被图吸引再看参数
3. 现场救急党——到了现场不知道怎么调
4. 随便逛逛党——刷灵感收藏备用

**场景分类**：按室内/室外 + 地点分类（咖啡厅、家里、街上、公园、地铁、商场等），用用户语言而非摄影术语。

**MVP功能（两个页面）**：
- 首页：瀑布流 + 一级（全部/室内/室外）+ 二级标签 + 搜索栏 + 付费锁标
- 详情页：大图多图滑动 + 场景描述 + 设备 + 参数卡 + Tips + 下载按钮 + 付费遮挡
- 去掉「我的」页面（预设量不多无需收藏模块）

**付费方案**：一次买断全部场景 ¥19.9，免费8-10个高频场景，付费解锁全部+未来更新。

**下载功能**：详情页下载参数卡片为图片到相册（带品牌水印），离线可查。
